# Практическая работа № 2. Поиск по Википедии

Консольная программа на C++17 ищет до десяти статей в русской Википедии и открывает выбранную статью в браузере по умолчанию.

## Сборка и запуск

Для сборки достаточно файлов проекта. Для поиска требуется интернет.

### macOS (MacBook с Apple Silicon или Intel)

Установите инструменты разработчика из Терминала и дождитесь завершения установки

```sh
xcode-select --install
```

Затем скачайте проект и соберите его

```sh
git clone https://github.com/Nevermore1218/lab_oop_2.git
cd lab_oop_2
make
./wiki-search
```

Сборка использует Apple Clang, системную библиотеку libcurl и входящую в проект библиотеку JSON. Статья открывается в браузере по умолчанию командой macOS `open`. При сборке создаётся программа для архитектуры текущего Mac.

## Как пользоваться

1. Введите тему, например `ЛЭТИ` или `C++`, и нажмите Enter.
2. Введите номер из полученного списка. Программа откроет статью и предложит новый поиск.
3. Чтобы вернуться к поиску без выбора статьи, введите `0` вместо номера. Команда `:q` завершает программу на любом приглашении.

## Структура

В папке `src` у каждого класса отдельные заголовочный файл и файл реализации.

| Класс | Ответственность |
| --- | --- |
| `ConsoleInput` | Чтение запроса и проверка номера статьи |
| `WikipediaClient` | Кодирование запроса с percent-encoding и HTTPS-запрос через libcurl |
| `SearchResponseParser` | Разбор JSON и извлечение заголовка и идентификатора каждой статьи |
| `ResultPrinter` | Вывод списка статей или сообщения о пустом результате |
| `BrowserLauncher` | Открытие ссылки с параметром `curid` через macOS open |
| `Application` | Цикл поиска и обработка ошибок |

Структура `Article` хранит данные одной статьи. Файл `main.cpp` запускает приложение. Для разбора JSON используется nlohmann/json 3.11.3 из `third_party/nlohmann`.
